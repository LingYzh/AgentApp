Public facade contract, package com.example.myapplication.device:

`class DeviceController(context: Context)` constructed once by root AgentApp. Use appContext.
- `var enabled: Boolean` persistent SharedPreferences global opt-in, default false; disabling prevents subsequent actions. Getter current.
- `fun status(): String` JSON with enabled, accessibility connected, screenshot supported, Shizuku binder/permission/user-service status, explanatory limitations; no sensitive screen content.
- `fun requestShizukuPermission()` called by visible UI, handle binder absent without crash.
- `fun connectShizuku()` user-requested bind; manage binder death and reconnect only when enabled/authorized. Errors visible in status.
- `suspend fun observe(): String` bounded JSON with `snapshot_id`, package, window id, display width/height/rotation, numbered nodes with text/description/viewId/bounds/actions. Cap ~150 visible useful nodes and ~20k chars, exclude password text. No accessibility connected => actionable error. Tree traversal must have total visit/depth caps, not merely result cap. All node operations on Main dispatcher; recycle obtained nodes as appropriate. Snapshot IDs scoped to service and version; do not keep unbounded node handles.
- `suspend fun act(args: JsonObject): String` one action, allowlisted `action` values: launch(package), click(node or x,y), long_click(node or x,y), set_text(node,text), scroll(node,direction), swipe(x,y,x2,y2,duration_ms), back, home, recents. UI actions require `snapshot_id` matching last observe AND expected foreground package/window; reject stale snapshots. For node actions re-resolve node and validate identity; do not act on stale node references. launch may use package manager launch intent with NEW_TASK; global back/home/recents require snapshot as well. Coordinates validated in display and correct rotation; duration bounded 50..2000ms, text max 4000 chars. Each result must distinguish accepted action from verified task success. Return fresh observe after action when practical. Never catch CancellationException as normal failure. Cancellable gestures with callback timeout; no blind retries. Per-controller mutex serializes observe/action/screenshot. Root adds per-agent-run ownership and permission gate externally. Disabling must also prevent queued actions; recheck inside lock.
- `suspend fun screenshot(): File` accessibility takeScreenshot API30+ (secure window errors explicit), cancellable timeout, close HardwareBuffer and bitmaps even if cancellation; output unique PNG in app cache device-captures, dimension cap ~1600 long side; cleanup bounded old files. Root will attach via native image callback and delete after import. No network/media projection.
- `suspend fun systemAction(args: JsonObject): String` Shizuku allowlisted operations: `list_apps` (bounded launchable/package info), `force_stop` (validated package; prevent stopping own UAH/Shizuku/system core), `open_settings` (fixed android.settings.SETTINGS), `keyevent` only BACK/HOME/APP_SWITCH via input injection. These are externally treated as mutating except list_apps by root. Avoid arbitrary command text; if fixed `/system/bin/am` command fallback needed, use ProcessBuilder array, timeout/cancellation and bounded output, do not concatenate shell command strings. UserService should be genuine bound privileged backend; at least force_stop and package listing must execute there and report current UID. Honor lack of permission with clear error. Bounded IPC: no screenshots over Binder.

Accessibility service `DeviceAccessibilityService` with companion connection StateFlow or singleton used by facade. Declare BIND_ACCESSIBILITY_SERVICE exported=true system binding, canRetrieveWindowContent/canPerformGestures/canTakeScreenshot, report view IDs and interactive windows if needed; description via resource or literal supported XML attribute.
