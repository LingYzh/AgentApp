# 本轮用户验收

1. 设置 → 共享存储应为“已允许所有文件访问”。让 Agent 重新读取原来的 notes.txt；仍失败时不要先改名，保留错误并告知代理读取诊断日志。
2. 用无关紧要的临时文件验收 delete_file：Accept Edit 应逐次确认，拒绝后文件保留；Readonly/Plan 不弹确认且拒绝；Auto 无 App 内弹窗。旧 Agent 若配置过工具白名单，请先勾选“删除文件”。
3. 发送后键盘收起。让 Agent 输出较长 Markdown/表格/代码块：停在底部时跟随；主动上滑时不抢位置；回到最底部或发送新消息恢复跟随。检查最终结尾可见、流式闪烁是否改善。
4. 模型配置选择思考强度，默认不额外发送参数。Claude 4.5 看预算说明，4.6 用自适应档位；Gemini 2.5 用预算，3 用级别；OpenAI 兼容用 Chat Completions 参数。自定义模板不自动注入。
5. 开启思考后连续执行至少两轮文件读取工具，确认工具回合能继续；重新进入会话再继续一次，以覆盖签名保存与回传。
6. 启动新版后可以通过 `adb ... exec-out run-as com.Ling.actant cat files/logs/runtime.jsonl` 获取日志。出现问题时提供大致时间和会话，代理可从日志定位；日志不包含正文与 API 密钥。

代理不代做上述实机交互测试。
