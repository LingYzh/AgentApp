## 最短实机检查

1. 使用已有图片头像 Agent 的历史会话，核对历史列表、抽屉最近项的图片；另看 emoji Agent、已删除 Agent 和缺图记录。搜索后进入管理，不应改动会话身份或默认 Provider。
2. 将同目录 `ui-v3-inline-code-regression.md` 的正文放入测试会话或文件阅读页。重点看行末的短符号、换行后的任务语法、链接和反引号底板；复制后应仍是原文。分别检查系统正常/大字体、浅/深色。
3. 在有执行记录的主会话里输入一段未发送文本、上滑并展开一个工具。进入右上角会话面板，再返回；输入、滚动、工具展开应保留，运行任务不中断。旋转后重复。
4. 在面板查看计划、各状态子代理和产物。历史 Diff 只取保存快照；当前文件已不存在时，记录仍保留，“查看当前文件”应提示真实错误。没有计划、子代理或产物时显示空状态。
5. 从会话面板打开子代理，再返回；子代理仍只读。主会话需要审批时，当前前台会话页面/面板只显示一份审批，不因查看计划或展开 Diff 自动批准。
6. 六类列表各打开“列表操作”，核对管理、导入、导出。文件导出进入选择，其他类别导出全部走原有选项；管理模式导出仅含已选项。搜索筛选后“全选”只增减可见项，原先隐藏选择保留且数量准确。删除确认不能扩大到后来新增的选择。
7. 模型配置普通态点 radio 只改默认、主体进入编辑；管理态只改变勾选。检查导入冲突、无 Key 导出、Skills ZIP 和完整备份入口仍可用。
8. 上下文面板压缩失败时，错误应显示在活动面板顶栏下；关闭面板后仍可在会话中查看/关闭同一错误。修正配置再试，不自动重跑请求。
9. 快速展开/收起工具和 Provider 高级区、切文件阅读/源码、切设置子页面；退出内容不能继续点击或获得 TalkBack 焦点。系统关闭动画后终态相同。

以上在 360/412dp、浅深色、系统大字体下核对；检查输入键盘、安全区、系统返回、TalkBack 展开状态和 48dp 触控范围。
