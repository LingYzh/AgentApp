# 本轮最短实机复测

1. 新草稿选择 Agent、模型、高强度、权限模式，并选择一个已有工作目录；不要发送，抽屉再点“新对话”。上述设置应立即继承，正文/附件为空；退出并重开 App 后再建仍继承。
2. 历史会话调整为另一档位/目录，再新建。默认应仍是第 1 步草稿设置。Agent 管理页“启动 Agent”使用该 Agent 自身模型。
3. 支持思考的模型打开快捷面板，白色圆形滑块始终存在。拖动松手生效；重置回 medium（不支持则可用中位档）。详细档位可滚到首尾，“返回滑块”在系统导航条上方；可再检查横屏/大字体。
4. 权限与目录 → 选择工作目录：逐层进入、点击路径祖先、上一级、常用位置均可导航；系统返回只回权限面板。允许范围可增加多个目录并删除；工作目录不在所选范围时显示错误。
5. 工作目录选一个已有目录，范围留空；让模型写入 `cwd-check.txt` 并调用 `pwd`（按当前权限模式审批）。文件与命令应位于选定目录；“查看当前文件”打开对应文件。需要清理时由用户自行删除。
6. 自选目录后添加一个文本附件，要求通过其工作区引用读取；附件仍可读。再执行一个子代理任务，确认子会话显示的工作目录/思考档位继承正确。

这些是用户操作步骤；本轮未自动操作手机 UI、发模型请求或在手机上创建测试文件。原型中的“跟随模型配置”文案已按本次需求替换为具体会话档位。
