# UI v3 第五轮实机验收（用户执行）

1. Android 保持深色，在应用设置手动切浅色：状态栏文字/图标应变深；再切深色、跟随系统，检查正文及两处系统栏。打开/关闭编辑弹层后仍保持正确颜色。
2. 展开已有非 Shell 工具记录：入参和回参在同一底板内，复制得到原始内容，长行换行/横向滚动、高度按钮正常；文件修改能在 Diff 下展开原始记录。
3. 打开 Agent、模型配置、Skill 编辑页：字段名位于输入框外，键盘弹出后内容可滚动，顶部保存可用。Provider 的能力、生成、高级组可折叠，拉取/测试状态清楚。
4. 文件详情切换阅读、源码、最近变更；只有有保存快照的文件显示最近变更。编辑时隐藏阅读 tabs，文本在编辑器内滚动，保存后返回阅读。
5. 记忆编辑和配置导入/导出底部面板在横屏/大字体下滚动正文，取消和确认始终可达。导入冲突仍可选择更新或副本。
6. 设置页调整循环数、选择子代理模型、进入命令管理/备份迁移后返回；主题、命令和模型选择重新进入仍保留。独立迁移入口进入对应的列表管理页。

这些是待用户执行的 UI 检查，不代表已经通过实机交互测试。
