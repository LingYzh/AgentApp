## 复现

1. 启动 `.Codex/tools/streaming-fixture-server.py`，仅监听本机 5582；对模拟器执行 `adb -s emulator-5554 reverse tcp:5582 tcp:5582`。
2. 模拟器中选择 `Stream Buffer QA / stream-fixture`。新会话分别发送下表提示；上游增量间隔均为约 100ms。
3. `pause-40` / `pause-300` 会在约三分之一处暂停 2 秒，随后一次发送约五批文本再继续。
4. `buffer-qa` 包含 Unicode、代码和延迟引用定义；观察首次缓冲、淡入、停顿排空和恢复。最终文本应完整，复制使用真实消息内容。

速率单位采用非 ASCII 一个码点或 ASCII 四字符的固定估算；八段相同 Markdown 共 1570 字符、1147 模拟单位。不是某供应商 tokenizer 的真实 tokens。
