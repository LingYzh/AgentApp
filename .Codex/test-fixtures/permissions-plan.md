# 本轮手机验收

1. 设置页开启「所有文件访问」，返回查看状态。让 Agent 列出 `/storage/emulated/0/Download`，再在你选定的测试目录创建、读取文本。其他 App 私有目录访问失败属于 Android 限制。
2. 先创建含三行的文件，再让 Agent 删除中间一行并改最后一行。收起工具时显示 + / - 统计，展开后内联显示红色删除、绿色新增；新建文件只有新增是正常情况。长行应自动换行，原始行号只在首个显示行出现。
3. 展开常规工具记录，默认应为可读摘要，只有点击详情才显示原始数据。
4. 默认 Accept Edit 请求 `pwd`，拒绝一次应不执行；再允许并记住。设置页删除记住的命令后，再请求应重新审批。含 `;`、重定向等复合命令不能快速永久放行。
5. 切换 Readonly，让 Agent 尝试写文件、保存记忆或运行命令，均应拒绝；读取不受影响。主代理可调用 enter_plan_mode，之后只能修改指定计划文件；子代理不可切换模式。
6. 切换 Plan 或要求 Agent 调用 enter_plan_mode；确认它只能修改指定计划文件。抽屉计划栏目应显示 Markdown 计划。
7. exit_plan_mode 弹出计划审阅：先提出修改意见，确认计划修改后重新提交；接受并以 Accept Edit 执行，模式应切换且自动继续执行。另测 Auto 接受分支。
8. 为会话限定一个测试目录，访问其同名前缀的其他目录、用 `..` 越界、执行任意 shell 都不应绕过限制。
9. 从总列表进入长历史会话应在最新内容处；向上翻历史时新输出不能强行拖回底部。

所有修改测试请使用可丢弃的测试文件。当前未提供 root/Shizuku 提权。
