# UI v3 本轮实机复测

由用户在 NX809J 执行；代理已按授权卸载旧签名版本并安装最终 APK，没有操作手机界面。重装后先配置模型及所需系统授权。

1. 用出现报错的 OAI 兼容配置发一句话，确认正文/思考正常返回；再发一次会触发工具调用的请求，确认工具分片及最终回复完整。
2. 首页首发：首发后无页面推进动画，左上角保持菜单按钮；点菜单或从左侧滑动打开全局抽屉。右上角仍可打开会话面板，返回先关闭面板。
3. 旧会话有内容时，在抽屉点“新对话”，立即回到空草稿；不发送多次点新对话，历史不新增空记录。再从最近会话或全部会话打开旧记录，正文和未发输入仍在。
4. 在正在回复时切到新对话，再打开原会话，检查原任务仍继续且不重复请求。首发后触发命令审批，检查审批正常显示、取消正常响应。
5. 有输入/附件时旋转屏幕、切后台和返回文件选择器，检查当前会话/草稿、输入和附件不丢失。
6. 思考面板检查：浅/深色暖色轨道、白圆滑块、两端标签、真实协议字段、右上重置；点击或拖动松手选档，打开详细档位，重置回模型默认。分别检查模型默认已设置与未设置，`none` 独立于跟随，未知默认不冒充中档。
7. 系统大字体下检查面板标题、字段和值可读，按钮可点，无裁切。
8. 当前会话 A → 全部对话 → 旋转屏幕 → 删除 A → 返回主界面，应显示空草稿，不出现“对话不存在”。
