# 流式延迟缓冲与新增文字淡入

- 用户授权本轮直接操作 Android Studio 虚拟机；使用 Herdr 中现有 agy CLI（w3:p1）执行限定文件任务，root 负责方案、Compose 接入、复核与模拟器验证。本轮没有创建其他 agent。
- `StreamingTextPacer`：首次 200ms 缓冲，排空后新数据重缓冲；按到达增量/时间估计速率，保留小数预算与约 320ms 的目标余量，发布间隔按速率选择 90/110/140ms。上游停顿继续排空，不再在 120ms 无数据时一次性刷完。
- 正常结束 200ms 内快速收尾；取消、错误、非追加替换、缩短、超过 4096 字符积压或超过 1s 的 tick 空档立即同步。保护代理对、组合符、变体选择符、肤色、ZWJ 和国旗对；不完整的代理对/ZWJ/单国旗指示符留待后续输入，结束完整释放。
- `StreamingTextReveal`：每批新增文字用原生 TextLayoutResult 范围遮罩淡入 220ms，旧文字不重播；帧时钟只在绘制阶段读取，动画结束释放离屏合成。支持正文、标题、引用、列表、表格和代码文本；WebView 公式/图表不做逐字淡入。
- `MarkdownContent` 保留完整 CommonMark 后台解析与相等块复用，解析不跟随动画帧。保存首次组合标记，历史、列表重入和 Activity 恢复采用当前快照；生命周期停止时暂停展示循环。
- `ChatScreen` 将主动停止和异常标记传入展示层，避免等待网络清理完成才停止播放；实际模型消费、工具执行和持久化不延迟。
- 模拟服务支持 `rate-40/70/120/300`、`pause-40/300` 和 `buffer-qa`。模拟速率单位为非 ASCII 一个码点或 ASCII 四字符，不是特定模型分词器的真实 tokens。必须在倒序用户消息中找场景标记：AgentEngine 会在用户消息后追加环境上下文，取最后一条会让速度档位失效。
- `SessionScreen.kt` 是本轮开始时已有的用户改动，未改动它。仓库没有 CLAUDE.md。
