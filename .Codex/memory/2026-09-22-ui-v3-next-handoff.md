## 已确认的产品行为，后续不可退回原型旧约定

- 会话就是主界面。首发原地显示；抽屉新对话创建新草稿，原会话继续可从历史进入；不创建空历史。
- 新会话页面最后调整的设置作为下一次新会话默认；思考强度首次 medium，不支持时映射至可用档位。Provider 不再配置默认思考强度。
- 工作目录是默认操作区；额外允许目录与之同级，文件工具范围为两者并集，额外目录为空时仅工作目录。Shell 从工作目录启动，目录范围不约束 Shell，仍按权限模式审批。
- 顶部反馈悬浮在顶栏下，不挤占正文。会话顶栏标题在上、Agent 名称在下，不放模型切换；输入卡片内模型选择保留。
- 用户不希望 harness 主动注入安全对齐提示词。不要借 UI 迭代恢复旧提示词或额外限制；已有明确授权/Android 能力/数据路径约束按当前项目约定处理。
- 当前由用户执行手机体验测试。后续代理准备构建、测试文件、必要环境和简短步骤；已有授权允许 ADB 覆盖安装。不得自行点击手机或创建/删除实机测试数据。
