# 原生 UI V3

## A：公共样式与局部过渡

- 使用 design/agentapp-ui-v3 的语义色；暗色实心按钮白色前景，不启用动态壁纸色。
- UiScaffold 将既有 SnackbarHost 放入顶栏下布局槽，反馈高度局部过渡；导航使用轻位移/淡入淡出，列表保留业务 key。
- 使用 Compose 原生动画时钟，遵循系统 animator duration scale；不对流式正文增加整段尺寸/淡入动画。
- 首次检查 testDebugUnitTest / assembleDebug 成功，lint 期间源码新增导致分析器报错；冻结源码后 A+B 三项检查均成功。

## B：工具记录

- 工具外层为透明、无描边、无水平 padding 的 48dp 点击行；展开真实布局高度，call/message key 保存状态。
- 命令从 argumentsJson 获取 command，从对应 toolCallId 返回获取结果。只解析 ShellCommandRunner 的精确退出码首行；未知退出码不推断。
- Shell 原地复制、换行、局部滚动和展开高度；空输出和未返回分别显示。
- InlineFileDiff 使用已有 FileChanges.diff，后台计算、LazyColumn 显示已保存快照；缺失/截断/预算降级明确说明，不显示精确统计。
- 主/子会话共用工具行；查看记录不执行工具、不授予权限、不重读历史文件。
- 实机测试由用户执行；本轮未操作设备。

## C：新对话草稿与首发

- 新增 NEW_CHAT 冷入口，历史保留；不在 onResume 重置导航，草稿没有历史 ID。
- ChatSessions 在 Activity ViewModelStore 内持有会话 VM；首发导航和历史重开复用同一执行 Job，Activity 最终销毁仍取消，非后台服务。
- SavedStateHandle 保存输入、附件引用、草稿参数及已提交 ID；外部选择器/旋转返回保留。草稿被消费后，返回入口创建新草稿。
- FileStore.commitDraft 使用独立回执预留 ID，原子替换会话文件；首次用户消息保存成功才清空草稿/发布导航回执。重复提交只产生一次历史。
- 单元测试覆盖并发首发、落盘失败后重试、回执恢复、不创建空历史，以及草稿 none/权限/目录/输入序列化。
- 本批 testDebugUnitTest、assembleDebug、lintDebug 均成功（batch-c-build.log）。

## D：V2 回归与最终修正

- 模型选择支持搜索/Provider 分组，每项显示 image/pdf/audio/video 有效能力和手动覆盖/接口发现/未声明来源；编辑页模型候选也显示能力。
- 思考使用独立离散滑块和同面板详细选项，中文、wireValue、适配字段同时保留；第零档是 null 跟随，none 是独立关闭档，松手才提交。
- 保留上下文八类真实估算、容量余量、未知容量和服务端报告；分段分母依据分类合计与容量。
- UiTextButton 统一 48dp 点击高度、文字操作暗色对比和局部按压反馈；主按钮仍使用 actionContainer + 白色前景。
- 附件列表稳定 ID，管理模式/Provider radio-checkbox/文件页签/记忆预览/思考详细面板局部过渡；退出的工具/思考内容屏蔽交互。
- 共享原生 Markdown 用于聊天、计划、Markdown 文件阅读与记忆预览；保留 SelectionContainer、安全链接和 120ms 解析采样。代码默认横滚，复制原文，仅用户换行操作启动局部尺寸过渡。
- 历史无调用参数的工具消息同样使用透明工具行，明确无法解析原始命令；文件页 Diff 复用内联呈现，不伪造降级统计。
- 原有读/写工具的文件导航保留为“查看当前文件”；历史 Diff 仍完全由保存快照内联展示，两者用途明确区分。
- 首发导航前后 observation 使用各自 Job 清理，防止旧页面停止新页面轮询；历史重新打开运行中的会话复用同一 writer。删除前取消并等待最终保存，防止运行任务重新写回已删除历史。
- 命令中止只识别引擎固定终止记录，不因失败输出含“取消”二字误标中止。
- 草稿回执根使用 FileStore 托管根校验，并纳入 Accept Edit 元数据保护；新增回执路径越界/写入拦截测试。
- 草稿 SavedState 序列化必须 encodeDefaults=true；否则 createdAt 的动态默认值可能在编码时被省略，恢复时变成新时间。最终测试捕获并修复此间歇性恢复差异。
- 四批及最终检查日志随交付保留；最终修正前已通过 191 项 JVM 测试（3 项 Windows 符号链接环境跳过），最终结果见交付说明。
