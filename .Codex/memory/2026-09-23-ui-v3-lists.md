# UI v3 六类列表与历史头像

## 本次改动

- 历史会话、Agents、工作区文件、Skills、长期记忆和模型配置在普通态通过顶栏更多按钮打开统一的底部“列表操作”菜单。菜单提供管理与多选、导入和导出；文件导出进入选择模式，文件导入沿用系统文件选择器。
- 会话、Agent、记忆和 Provider 的“导出”接各自独立迁移的全部导出回调；Skills 的“导出全部 ZIP”保留现有 ZIP 分享，所选项目仍通过管理栏导出。
- 管理栏显示已选数量、搜索结果内全选、导出已选和二次确认删除。删除按钮使用危险色，忙碌时禁用操作，退出管理时清空选择。搜索筛选不清除已选项目，但全选只作用于当前可见项。
- Provider 正常态保留 radio 选择默认配置，管理态使用 checkbox；切换期间离场控件和离场管理栏停止响应。Provider 编辑页的折叠表单改为单个展开/收起高度动画和旋转箭头，收起期间内容不响应输入。
- 历史会话行从当前 Agent 记录取得名称、emoji 和头像路径并使用 `AgentAvatar`；头像文件不存在或解码失败时回退 emoji。同一路径文件替换后按修改时间和长度刷新图片请求与失败状态。已删除的 Agent 不使用其他 Agent 的头像。历史行与记忆行补充稳定 key 对应的列表项动画。
- `SelectionScope` 将当前搜索结果内全选、数据刷新后的 ID 过滤和删除确认快照收敛为纯函数；JVM 回归测试覆盖隐藏选择保留、空搜索结果、已删除 ID 和确认后新增选择的边界。
