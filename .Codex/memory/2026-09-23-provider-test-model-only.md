# 供应商测试模型与会话选择解耦

- 用户修订：供应商编辑页所选模型只用于测试连接，不参与其他功能。列表删除默认单选、默认标签、模型名、协议字母图标，展示名称、协议和去重后的模型数量；管理态仍支持多选。
- 编辑页明确标注测试连接模型；单独提供手动添加模型 ID，测试模型不会自动加入模型列表。模型子项删除默认标签。
- 会话模型选择器、Agent 编辑、子代理设置和 harness 模型目录不再回退到供应商测试模型。ModelResolver 仅解析会话明确选择或 Agent 配置，供应商/模型成对解析，已删除供应商不会把模型转发到其他端点。
- 用户确认首次或上次模型已不可用时保持未选择，聊天发送按钮禁用；新会话快照在模型目录中验证记录，测试模型改变不会改变会话模型。
- 子代理继续遵循设置指定、工具参数、继承主代理的优先级；指定其他供应商但未指定模型时给出明确错误，不使用测试模型。
- 保留旧序列化字段，避免破坏导入导出；ProviderConfig 的执行副本仍由明确会话选择写入 model 后交给协议层。
- 验证：253 项单测中 250 通过、3 跳过、0 失败；assembleDebug/lintDebug 成功，lint 39 warnings/3 hints 与基线一致；git diff --check 通过。模拟器实际查看列表 24 个模型及新会话未选择状态。新版已覆盖安装到手机并保留数据，未提交或推送。
