# 供应商模型设置页

## 本次改动

- `ProvidersScreen.kt` 的 Provider 卡片按 UI v3 的布局显示类型标识、协议名称、默认模型、默认 radio 和默认状态；管理态用 checkbox，单项删除仍可通过管理模式只选该供应商后删除。
- 供应商编辑页有独立且默认展开的模型列表。模型项进入页内设置子页，展示模型能力覆盖与上下文 token 设置；“完成”与返回操作只回到供应商草稿，只有供应商页顶部“保存”提交。
- 接口发现能力和手动覆盖继续分开保存，获取模型列表不会覆盖用户的模型能力覆盖。供应商保存失败会留在编辑页并保留草稿。
