# UAH PC 版 Harness 功能设计

> 状态：需求设计稿。目标平台为 Windows 11 首发；依据当前 Android 版功能、视觉规范及本轮确认的 PC 需求整理。

## 1. 产品定位与边界

- PC 版是独立桌面应用，继续使用 Used AI Harness / UAH 品牌。项目、会话、模型接入、Agent、技能、记忆、文件、权限和工具记录保留 Android 版的概念，并针对本地代码项目扩展。
- PC 版以本地目录为项目；普通目录和 Git 仓库都可添加。会话必须绑定项目，可以在项目下创建多个会话。
- 与 Android 版通过显式导入、导出配置和会话交换数据，不做实时同步。PC 首版提供 Windows 桌面与内置浏览器控制，不通过 ADB 控制 Android 手机。
- 模型来源分为“自配 API”和“官方订阅运行时”。两者共用 UAH 的项目列表和对话界面；实际 Agent 执行、可用工具及权限规则以选中的运行时为准，界面明确显示能力差异。

## 2. 主窗口：左、中、右三段式

| 区域 | 内容与交互 |
| --- | --- |
| 左侧项目栏 | 顶部固定“新对话”；其下为搜索和快捷入口（Agent、模型与账号、MCP、插件与技能、记忆、文件、设置）；下方按本地项目归类会话。显示运行、等待审批、已停止等状态，并支持项目和会话的常用管理操作。 |
| 中间对话区 | 顶部显示项目、工作目录、Agent、运行时与当前任务状态；正文显示流式回复、思考摘要、工具调用、审批、错误及附件；底部固定输入框、模型、思考档位、权限模式、目录范围与停止按钮。用户消息为浅暖灰气泡，助手正文保持无气泡的阅读式排版。 |
| 右侧扩展栏 | 用可关闭、可固定的标签页承载计划、后台任务、子代理与子会话、文件 Diff、内置浏览器、终端。一个会话可同时打开多个标签；切换左侧会话时保留各自的右栏状态。 |

三栏宽度可拖动。窗口不足以同时容纳三栏时，优先保证对话宽度，右栏改为可唤出的覆盖面板；左栏可收起。审批、停止和错误状态始终可见。界面借鉴 Codex 和 Claude Code Desktop 的信息组织，不逐像素复制；沿用 Android 版暖白 `#FAF9F5`、暖炭灰 `#262624`、陶土强调 `#A34F36`，并保留系统/浅色/深色主题。

## 3. 对话、项目与并发

1. 新对话先是草稿；首次有效发送后才保存为会话。会话绑定项目、工作目录、Agent、模型来源、权限模式和可访问目录。
2. 同一 Git 项目目录已有**正在执行或等待审批**的会话时，创建另一个会话立即明确提示，并让用户选择“新建独立 Git worktree”或“直接使用当前目录”。若该目录仅有已停止的历史会话，则不弹提示。普通目录无法使用 worktree；并发使用时明确提示文件冲突风险。
3. 会话离开当前页面后继续运行；多个会话可以并行。关闭 UAH 时中止由 UAH 管理的运行任务，保存中止原因与已完成记录；重启不自动续跑。
4. 会话可以查看历史、分支、重新生成适用的回复，并保留原有的附件、Markdown、公式、Mermaid、上下文与压缩、计划审批等能力。跨不同运行时切换模型时，新建分支会话并明确提示上下文迁移范围，不把一个运行时的内部状态冒充为另一个运行时可继续的会话。

## 4. 每轮文件改动与右侧 Diff

- **每轮模型回复末尾都显示本轮文件改动区**；无改动时显示“本轮无文件改动”。按新增、修改、删除、重命名列文件及增删行统计，提供点击入口。
- 记录本轮文件工具和 Shell 引起的实际变化。以工具事件、运行前后文件快照和工作目录监测合并归因；在同一目录并行运行、外部程序介入或变动超出监测范围时，标注“归属不确定”，不伪造精确归因。
- 点击列表文件，在右栏打开**该轮保存的历史 Diff**，显示上下文、行号、增删色与路径；另设“打开当前文件”。历史 Diff 不依赖当前磁盘内容。二进制、大文件或快照缺失时展示可核实的元数据及原因。
- 文件列表和 Diff 归属到会话及轮次，后台任务结束后也可复查；终端和子代理产生的改动进入对应父任务的本轮汇总，并保留来源标记。

## 5. 右侧扩展栏详细功能

| 标签 | 首版功能 |
| --- | --- |
| 计划 | 查看计划步骤、状态与执行记录；计划模式的执行批准留在明确的审批入口。 |
| 后台任务 | 汇总运行中、等待审批、已完成、失败和中止的会话；可切换、停止并查看进度。 |
| 子代理 | 展示父子关系、运行状态和子会话正文；沿用 Android 版单层委派约束，不能由子代理再次委派。若官方运行时支持不同层级，按其真实结果展示并标明来源。 |
| 文件 Diff | 多文件标签、历史 Diff、当前文件入口、复制路径与打开所在目录。 |
| 内置浏览器 | 地址、前进/后退、刷新、标签页、手动登录与 Agent 操作记录；使用独立浏览器配置文件。 |
| 终端 | 项目目录中的交互终端、多个标签、命令输出与退出状态；模型工具调用记录和用户手动终端明确区分。 |

## 6. 模型与订阅账号

| 接入方式 | UAH 中的入口 | 执行方式 |
| --- | --- | --- |
| 自配 API | OpenAI 兼容、Anthropic、Gemini、自定义模板；保留模型目录、能力声明、思考档位和连接测试 | UAH 自有 Agent 引擎，沿用现有工具与权限模型 |
| ChatGPT/Codex 订阅 | “订阅账号 → Codex”：安装状态、官方登录、当前账号、可用模型与连接状态 | 通过 Codex App Server 在 UAH 内启动和管理会话 |
| Claude Code 订阅 | “订阅账号 → Claude Code”：安装状态、官方登录、当前账号、可用模型与连接状态 | 调用用户自行登录的、未修改的 Claude Code 官方客户端 |
| Google AI Pro/Ultra 等订阅 | “订阅账号 → Antigravity CLI”：安装状态、官方登录、当前账号、可用模型与连接状态 | 调用 Antigravity CLI 官方运行时 |
| Gemini CLI | 保留 CLI 连接能力及受支持的 API Key/企业认证入口 | 不把已经迁移到 Antigravity CLI 的 Google 订阅额度标成 Gemini CLI 可用 |

每个官方服务首版只管理其**当前登录的一个账号**。UAH 显示状态并启动官方登录、退出及模型查询流程，不复制或改写官方凭据，不把订阅凭据当作通用 API Key。账号额度、思考档位、工具、子代理等仅在运行时提供相应数据时展示；缺失时明确标记不可用。模型选择器按“自配 API / 订阅运行时”分组，切换来源前显示会话与权限的实际影响。

参考 CC Switch 的统一账号状态、供应商配置与 MCP/Skills 管理思路；UAH 的订阅任务仍通过对应官方运行时执行。

## 7. MCP、插件和技能

- MCP 首版支持本机 `stdio` 与远端 Streamable HTTP，覆盖工具、资源和提示词；远端按服务器要求完成登录授权。显示连接、认证、工具清单、调用记录与错误。全局添加服务器，各项目分别启用或停用，之后仍受 Agent 工具权限及会话权限收窄。
- 插件首版可从本地目录或包导入，优先兼容可识别的 Agent Plugins、Codex 及其他公开格式。安装前预览清单、Skills、Agent 定义、MCP、规则和 hooks；保留原始包与来源信息。全局安装，项目内启停。
- 可执行 hooks 在安装时只识别并展示；每一项须由用户单独启用并确认执行权限后运行。卸载、更新和冲突处理应有预览与恢复路径。
- UAH 自有引擎直接使用已启用的 MCP/插件。订阅运行时通过适配层传入其支持的 MCP、Skills 与插件配置；对格式或能力差异逐项显示，不静默修改用户在官方客户端中的既有全局配置。

## 8. Windows computer use 与浏览器

- 首版目标为**当前 Windows 11 桌面**和 UAH 内置浏览器：观察屏幕与可访问控件、截图、点击、键入、滚动、窗口切换及停止。优先使用 Windows UI Automation 的语义控件操作，必要时使用受校验的坐标输入；浏览器优先使用其可验证的页面结构。
- 提供默认关闭的总开关，并叠加 Agent 工具授权和会话权限模式。首次操作目标应用或网站时请求明确授权，可记住用户主动允许的目标；用户随时可停止。只读和计划模式禁止写入动作，需审批模式逐次确认，自动模式按已授予的范围执行。
- 浏览器采用与系统浏览器分离的配置文件，网站账号由用户在内置浏览器登录。模型首次访问网站需授权；浏览器登录态不提供给模型 API、网络搜索服务或其他网站。
- 同一时刻由一个父会话持有屏幕操作权；子代理共享该租约。每次动作校验最近观察到的窗口、应用/网站与界面状态；目标变化后重新观察。任务停止或 UAH 退出时取消后续动作。
- 对订阅运行时，优先通过 UAH 管理的本地工具/MCP 接口暴露这套能力，并让 UAH 的总开关与目标授权继续生效；逐个验证官方运行时的工具接入和审批流程，界面据实显示支持状态。

## 9. 数据、迁移与验收

- PC 数据独立保存项目、会话、历史 Diff、账号连接状态、模型配置、Agent、技能、记忆、MCP 与插件启用关系。敏感凭据使用适合 Windows 的安全存储；导出前明确列出是否包含密钥或敏感会话内容。
- 导入 Android 版配置与会话时先校验并预览冲突，用户选择更新、副本或跳过；Android 专属设备控制配置不自动变成 Windows 授权。导出遵循同样的可预览原则。
- 首版验收至少覆盖：三栏与右侧标签切换；自配 API 与三个官方订阅运行时在 UAH 界面里完成登录、选模、对话与停止；仅在有活动会话时出现 worktree 选择；文件工具和 Shell 改动在每轮末尾可见并能复查历史 Diff；后台切换继续运行、退出中止；本地/远端 MCP、项目插件启停及 hooks 授权；Windows 桌面和内置浏览器的观察、动作、授权与停止。
