# 图形源与重建

UAH 单色合字是工程化定稿。以 artwork/geometry.json 的三个路径及变换为准；SVG 与 Android VectorDrawable 使用完全一致的路径。

- 自适应画布：108×108，中心54,54。主体缩放0.82，平移(9.72,7.26)。
- 旧版启动图标与普通1024px图：按中心72×72显示区输出，与典型自适应显示尺度对应。
- 透明标志没有背景；导出的圆形/圆角只用于普通PNG，不用于自适应分层。
- 白色和charcoal标志形状不变，仅改变fill。
- preview图片为本包资产的合成图；图像工具输出的概念板不参与工程资源，也不作为验收基准。

不依赖字体。不要求安装任何字体；不提供字体文件。主文件可以用Figma、Inkscape或Android Studio按矢量查看。
