# AgentApp UI v3 · 轻量对话流

基线：`LingYzh/AgentApp master@2c947234ab0d29ede6e999193717288363195b7a`。核查日期：2026-09-22。

这是完整的浏览器交互原型与原生 Compose 实施交接包，不是 APK，不含真实 API 请求、命令执行或 Android 文件授权。本轮没有修改或提交 GitHub 仓库。

## 开始查看

直接打开 `index.html`，无需 npm、联网、服务器或额外字体。桌面侧栏可访问 26 个页面；右侧有设计说明与“重播交互动效”。窄窗口自动呈现手机布局。顶部可切换 360/412 宽度、浅深色和动效开关。系统减少动态效果偏好优先于原型开关。

优先体验：第 26 页“工具记录 · 样本” → 展开“运行了命令” → 展开“已编辑 FilesScreen.kt +1 −1”。状态标签可切换执行中、待批准、失败、无输出、中止和缺少快照。完成会话和只读子代理也已使用同一套轻量工具行，不是仅更换设计样本。

进入原型默认是新对话。只有第一次有效发送才产生一条演示历史；反复打开新对话不会制造空记录。`?screen=tool-lab&theme=dark` 之类参数只用于评审直接打开指定界面，不是正式 App 启动逻辑。

## v3 改动

- 命令收起只有状态动作文字；展开在原地查看实际命令和输出。
- 文件编辑收起显示文件名和增删行数，展开为内联 Diff；没有包围整条记录的线框和嵌套卡片。
- 同页状态、面板替换、列表管理、折叠高度、顶栏反馈、主题和按钮状态补上连续过渡，保留原有 DOM/焦点/滚动。
- 统一图标与文本的水平排列和垂直居中；下拉箭头置于文本右侧。
- 明确原生启动页改为新对话草稿；首次发送再创建持久会话，后台恢复不重置当前会话。
- v2 的白色按钮前景、分段上下文、媒体能力图标、思考滑块、顶部消息、Provider 单多选和 Markdown 排版全部保留。

## 演示与测试边界

所有模型名、用量、执行结果和文件内容都是样本。请勿输入真实密钥；表单主要保存在内存，刷新恢复样本。没有外部模型服务，没有 Shell 执行能力。部分导出按钮仅导出演示文件或提示范围。

验证环境为桌面 Chromium + Playwright；独立 HTML 通过 `set_content` 加载，因为当前测试容器策略阻止 `file://`。没有验证用户设备浏览器直接打开行为、Android IME/TalkBack、原生返回手势或 Compose 帧率。截图是浏览器参考，不是运行中的 APK。
